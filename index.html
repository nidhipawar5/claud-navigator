Screen D — Annotation guide

1

Navigator header bar

Always-visible: task name, confidence %, timing. Dark background anchors the panel visually.

2

Signal tags

Detected intent signals shown as colored chips. Color = category (blue=structural, purple=iterative, amber=formatting).

3

Complexity score bar

0.0–1.0 visual scale. >0.7 = Agent recommended. 0.3–0.7 = Workflow. <0.3 = Direct Prompt.

4

Options table

Ranked by confidence. Click row A or C to override → Screen H. Highlighted row = recommended.

5

Primary CTA

Keyboard-mapped: Enter = accept recommended, Tab = explore alternatives. Auto-executes in 5s.

Routing Decision Logic
Complexity score thresholds map user intent profiles to optimal execution paths
User intent profile Route Complexity score Decision rule
Simple Q&A, lookup, single-turn Direct Prompt < 0.3 Standard knowledge retrieval. No extra routing overhead.
Structured output, templates, pitch decks Structured Workflow 0.3 – 0.7 Sequential generation or specific formatting required.
Complex research, code refactoring, multi-tool Agent (Multi-step) > 0.7 Requires tool use, self-correction, or deep context.
